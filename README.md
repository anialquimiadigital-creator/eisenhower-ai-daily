## 💡 Por que isso existe

Você acorda sem saber por onde começar. Tem 30 coisas na cabeça, urgências chegando pelo WhatsApp e aquele projeto importante que nunca sai do lugar.

Isso não é problema de esforço. É problema de **priorização**.

O presidente Dwight Eisenhower comandou a Europa durante a 2ª Guerra Mundial gerenciando centenas de decisões simultâneas. O método que ele usava é simples: **separa o urgente do importante**. Porque o que grita mais alto raramente é o que mais importa.

Este projeto transforma essa lógica em um sistema completo — com ou sem IA — rodando dentro do Notion, do jeito que você já usa.

## 🧠 A Matriz de Eisenhower

```
                  URGENTE          NÃO URGENTE
              ┌────────────────┬────────────────┐
  IMPORTANTE  │ 🔴 Q1 - FAZER  │ 🟡 Q2 - AGENDAR│
              │   AGORA        │                │
              ├────────────────┼────────────────┤
  NÃO         │ 🟠 Q3 - DELEGAR│ ⚫ Q4 - ELIMINAR│
  IMPORTANTE  │                │                │
              └────────────────┴────────────────┘
```

**Q1** — Urgente + Importante: faça agora, sem negociação.
**Q2** — Importante mas não urgente: onde mora o crescimento real. Agende e proteja.
**Q3** — Urgente mas não importante: delegue sempre que puder.
**Q4** — Nem urgente nem importante: elimine sem culpa.

A maioria das pessoas passa o dia apagando incêndio no Q1 e nunca chega no Q2. O sistema foi feito pra mudar isso.

> _Baseado no método do presidente Dwight D. Eisenhower, popularizado por Stephen Covey em "Os 7 Hábitos das Pessoas Altamente Eficazes"._

## 🤖 Caminho 1 — Com Claude Code (versão com IA)

A skill tem **7 modos** que você ativa em linguagem natural:

| Modo | Como ativar | O que faz |
|------|-------------|-----------|
| `setup` | "criar minha estrutura" | Cria os 3 bancos + workspace + dashboard no Notion automaticamente |
| `morning` | "bom dia" | Ritual matinal: mostra prioridades e define seus Top 3 do dia |
| `capture` | "captura: [lista]" | Despeja tudo — Claude classifica em tarefa, ideia ou projeto |
| `add-task` | "adiciona tarefa X" | Adiciona uma tarefa com quadrante calculado automaticamente |
| `evening` | "fechando o dia" | Marca concluídos, celebra wins, reagenda o que ficou |
| `update` | "atualiza urgências" | Revisa prazos e reclassifica quadrantes automaticamente |
| `weekly-report` | "relatório semanal" | Gera relatório narrativo completo para seu gestor |

**Como instalar:** veja o [guia de instalação](./docs/instalacao-claude.md)

## 📋 Caminho 2 — Sem Claude Code (versão manual no Notion)

Sem precisar de nada técnico. Você cria os bancos no Notion seguindo o [guia de montagem](./notion/guia-de-montagem.md) e usa os quadrantes manualmente.

Leva cerca de **20 minutos** para configurar e funciona em qualquer plano do Notion (inclusive o gratuito).
